## 2. Newly added dependency advisory scan — published RC1

**Before this step:** Root `Gemfile` is only `gemspec`; **the repository does not commit a root `Gemfile.lock`**. A statement that "all dependency versions are clean" without resolving exact versions would be unsupported.

[Step 31-3 RC1 RubySec audit workflow](../../.github/workflows/v0.3-rc1-dependency-audit.yml) generates independent RubyGems host Bundler lockfiles for **published `a2a-rails = 0.3.0.rc1`**, matrix Ruby **3.3/3.4/4.0** × Rails **~>8.0.0 / ~>8.1.0**, then installs exact resolved graphs. It:

1. Verifies loaded Gem `0.3.0.rc1` and `Bundler::Source::Rubygems` (not Git or workspace source).
2. Records `Gemfile.lock`, resolved Ruby/Rails version, and lockfile SHA256 per job.
3. Runs installed [rubysec/bundler-audit](https://github.com/rubysec/bundler-audit) `bundle-audit check --update` against the current fetched RubySec advisory database.
4. **Fails** on detected vulnerable Gems, not masked by `continue-on-error` or ignored advisory IDs, and uploads per-job logs and lockfile (14-day retention).
5. Supports manual rerun via `workflow_dispatch`; dependency versions and the advisory DB can change, so it is **a dated snapshot, not frozen stable provenance**.

**Verified Step 31-3 audit result:** [PR #123 audit run #38051087447](https://github.com/cuichangquan/a2a-rails/actions/runs/38051087447) **6/6 SUCCESS**. All six jobs explicitly logged `No vulnerabilities found` from **bundler-audit 0.9.3**, using a freshly updated ruby-advisory-db, and verified installed published RubyGems `0.3.0.rc1` provenance. The exact resolved Rails versions were **8.0.5.1** and **8.1.4**:

| Ruby / Rails | Installed and resolved Gem | RubySec result |
| --- | --- | --- |
| Ruby 3.3.12 / Rails 8.0.5.1 | `a2a-rails 0.3.0.rc1` from RubyGems | **PASS — no known matching advisories** |
| Ruby 3.3.12 / Rails 8.1.4 | Same public RC1 | **PASS** |
| Ruby 3.4.11 / Rails 8.0.5.1 | Same public RC1 | **PASS** |
| Ruby 3.4.11 / Rails 8.1.4 | Same public RC1 | **PASS** |
| Ruby 4.0.7 / Rails 8.0.5.1 | Same public RC1 | **PASS** |
| Ruby 4.0.7 / Rails 8.1.4 | Same public RC1 | **PASS** |

Every job retained a per-run resolved `Gemfile.lock`, SHA256 and audit output as a [GitHub Actions artifact](https://github.com/cuichangquan/a2a-rails/actions/runs/38051087447). Artifacts are retained for 14 days. The result means **no matching advisories in the fetched RubySec database for these six resolved RubyGem graphs at scan time**; it does **not** prove arbitrary versions or environments are vulnerability-free. A detected advisory in a future run must be triaged by version, affected code, severity and mitigation; any known unmitigated Critical/High release-scope flaw blocks stable GO.

**Limits of RubySec scan:** advisory DB completeness is not guaranteed; it scans **RubyGems packages**, not the Ruby interpreter, Node/Python/Go dependencies, container OS, or a production Rails app's specific plugin set. The future stable `0.3.0` lockfile and actual consumer host must be audited again.
