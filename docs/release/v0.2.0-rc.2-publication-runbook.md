## 1. Obtain and verify the exact release artifact

From a terminal, extract the ZIP downloaded from the Step 23 workflow and point `GEM_PATH` to its extracted `.gem` (or use the separately preserved, checksum-verified copy):

```sh
export GEM_PATH="/absolute/path/to/a2a-rails-0.2.0.rc2.gem"
export EXPECTED_SHA="d65fdd65003987ece96f0a90a4cf28563929be99d26658deeb275fca30c5d694"

test -f "$GEM_PATH" || exit 1
ACTUAL_SHA="$(shasum -a 256 "$GEM_PATH" | awk '{print $1}')"

```

Verify the displayed Gem name is `a2a-rails` and its version is `0.2.0.rc2`.

## 2. Publish GitHub tag and pre-release

Run from a local authenticated checkout with the GitHub CLI (`gh auth status` should succeed):

```sh
git fetch origin main --tags
export TAG="v0.2.0-rc.2"
export VERIFIED_COMMIT="efdec49daa0ef20edff26d4d198a8afc91567535"

test "$(git remote get-url origin | sed -E 's#^git@github.com:#https://github.com/#; s#\.git$##')" = "https://github.com/cuichangquan/a2a-rails" || {
  echo "Wrong repository"; exit 1;
}
git cat-file -e "$VERIFIED_COMMIT^{commit}" || exit 1
if git rev-parse -q --verify "refs/tags/$TAG" >/dev/null || git ls-remote --exit-code --tags origin "refs/tags/$TAG" >/dev/null 2>&1; then
  echo "Tag already exists: inspect it before proceeding"; exit 1
fi
git tag -a "$TAG" "$VERIFIED_COMMIT" -m "a2a-rails v0.2.0-rc.2 release candidate"
git push origin "refs/tags/$TAG"

gh release create "$TAG" "$GEM_PATH" \
  --verify-tag --prerelease \
  --title "a2a-rails v0.2.0-rc.2" \
  --notes-file docs/release/v0.2.0-rc.2-release-notes.md
```

The release notes file is on **main after Step 25 docs merge**, while the tag must point to the **exact Step 23 verified commit**, not later main. If CLI is unavailable, the equivalent GitHub web UI pre-release can be created, selecting the exact commit as tag target and attaching the verified Gem; check whether the tag already exists before creating it.
