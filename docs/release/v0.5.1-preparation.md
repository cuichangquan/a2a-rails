## Dependency compatibility correction

The published `agent2agent 2.0.0` depends on `json_schemer 2.5.0`, whose
ECMAScript regular-expression adapter calls `implements`. `regexp_parser 2.13.2`
made that class method private. In this combination `json_schemer` chooses the
instance fallback and loading the SDK fails with `NoMethodError` for `implements`.
This is an upstream dependency compatibility regression, not a vulnerability claim.

The distributed gemspec adds `regexp_parser ~> 2.0, < 2.13.2`. The lower range
matches json_schemer's existing requirement, retaining previously compatible
2.x lockfiles rather than imposing a new minimum of 2.13.1. Fresh resolution
selects the known-good 2.13.1. The upper bound also excludes unverified future
versions until the upstream adapter fix is validated. No public API, protocol,
persistence, Handler, SDK boundary implementation or global monkey patch changes.
During preparation, the README continued to identify the then-published 0.5.0.

This is temporary. Remove or relax the upper bound only after an upstream
json_schemer/SDK release compatible with the changed parser API is available,
the consumer dependency graph selects that fix, and fresh installed-package,
Ruby/Rails, schema and real protocol/HTTP/TLS checks pass. Do not delete the guard
just because another parser version appears. Older locked applications remain
responsible for updating and auditing their own dependency graphs.

## Verification and fixture isolation

The canonical build-once workflow inspects the emitted Gem's runtime dependency
and tests the same archived exact-head artifact, not a checkout-only dependency.
A separate clean-install job reproduces the precise published 0.5.0 / SDK 2.0.0 /
schemer 2.5.0 / parser 2.13.2 failure, then installs the candidate without a host
parser pin and asserts 2.13.1 resolution, successful require and JSON Schema
pattern validation. Unrelated errors cannot count as the expected reproduction.
The ordinary installed Rails/HTTP/authentication/interop matrices remain required.

Historical published 0.2.0 and 0.2.0.rc2 compatibility hosts and the standalone
SDK spike intentionally do not consume this gemspec. Their disposable fixture
Gemfiles explicitly select parser 2.13.1. Original published Gem versions, source
pins, package checksum verification and functional assertions remain unchanged;
these test-only dependency selections do not rewrite historical packages.

Local Ruby was unavailable in the fresh cloud workspace. Static diff/YAML/shell
validation is not runtime evidence. Record exact candidate HEAD, independent
review, actual CI results and canonical artifact SHA256 in the draft PR; do not
claim completion while required checks remain unverified or fail. The known
informational TCK remains partial (CORE-SEND-003), not full A2A conformance.
