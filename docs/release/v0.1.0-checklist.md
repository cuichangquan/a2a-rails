# v0.1.0 Release Checklist

This checklist is the release procedure for `a2a-rails` v0.1.0.

Step 15-13 prepares this checklist only. Do not publish, tag, or create the GitHub Release until the release-execution step is explicitly approved.

## 1. Before Release

- [ ] Confirm `main` contains the complete Step 15-13 release-candidate changes.
- [ ] Confirm `A2A::Rails::VERSION` is exactly `0.1.0`.
- [ ] Confirm `CHANGELOG.md` contains the `0.1.0` entry.
- [ ] Confirm `docs/release/v0.1.0.md` is final.
- [ ] Confirm gemspec metadata points to the canonical repository, changelog, documentation, and issue tracker.
- [ ] Confirm `rubygems_mfa_required` remains `true`.
- [ ] Confirm the MIT `LICENSE` is present and included in the Gem.
- [ ] Confirm Ruby requirement is `>= 3.3`.
- [ ] Confirm Rails requirement is `>= 8.0, < 8.2`.
- [ ] Confirm `agent2agent ~> 2.0.0` remains the SDK dependency.
- [ ] Confirm all CI jobs are green.
- [ ] Confirm Gem suite has 0 failures / 0 errors / 0 skips.
- [ ] Confirm the packaged-gem smoke passes from a clean Rails application.
- [ ] Confirm the repository is ready to be publicly accessible before or at the time RubyGems metadata begins pointing users to it.
- [ ] Confirm the RubyGems name `a2a-rails` is still available immediately before publishing.

## 2. Build Final Artifact

From the exact release commit:

```bash
gem build a2a-rails.gemspec
```

Then record the final artifact digest:

```bash
shasum -a 256 a2a-rails-0.1.0.gem
```

- [ ] Confirm the artifact is named `a2a-rails-0.1.0.gem`.
- [ ] Confirm required Engine, routes, generators, templates, README, LICENSE, and CHANGELOG files are packaged.
- [ ] Record the final SHA256 in the release record.
- [ ] Install the exact artifact locally or in a clean container and confirm `A2A::Rails::VERSION == "0.1.0"`.

## 3. Tag

Create the release tag only after the final artifact checks pass:

```bash
git tag -a v0.1.0 -m "a2a-rails v0.1.0"
git push origin v0.1.0
```

- [ ] Tag `v0.1.0` points to the exact release commit on `main`.
- [ ] No source changes occur between the verified release commit and tag creation.

## 4. Publish RubyGem

Publish only the final verified artifact:

```bash
gem push a2a-rails-0.1.0.gem
```

- [ ] Complete RubyGems MFA / WebAuthn verification.
- [ ] Confirm `gem fetch a2a-rails -v 0.1.0` succeeds.
- [ ] Compute SHA256 of the fetched RubyGems artifact and compare it with the locally verified final artifact.
- [ ] Confirm `gem install a2a-rails -v 0.1.0` succeeds in a clean environment.
- [ ] Confirm `ruby -ra2a-rails -e 'puts A2A::Rails::VERSION'` prints `0.1.0`.

## 5. GitHub Release

Create a GitHub Release from tag `v0.1.0` using `docs/release/v0.1.0.md` as the release-note source.

- [ ] Release title: `a2a-rails v0.1.0`.
- [ ] Tag: `v0.1.0`.
- [ ] Release notes match the reviewed source document.
- [ ] Include the final RubyGem SHA256 in the release evidence.
- [ ] Confirm repository visibility is public when the public release is announced.

## 6. Post-Release Verification

- [ ] RubyGems page shows version `0.1.0`.
- [ ] RubyGems homepage/source/changelog/documentation links resolve publicly.
- [ ] GitHub Release is visible.
- [ ] README Quick Start is accurate for the published Gem.
- [ ] In a fresh Rails application, run:

```bash
bundle add a2a-rails
bin/rails generate a2a:rails:install
bin/rails generate a2a:rails:agent echo
```

- [ ] Confirm Agent Card retrieval succeeds.
- [ ] Confirm Echo `SendMessage` reaches `TASK_STATE_COMPLETED`.
- [ ] Confirm no accidental secret, credential, private URL, or release-only temporary file was published.

## 7. Release Record

After publication, record:

```text
Release commit: <sha>
Tag: v0.1.0
RubyGems version: 0.1.0
Final artifact SHA256: <sha256>
GitHub Release: <url>
RubyGems: <url>
CI run: <url>
Post-release smoke: PASS / FAIL
```

If any verification fails after publication, do not overwrite or mutate the released gem. Prepare a new patch version instead.
