The default `MemoryStore` is process-local. Production asynchronous execution requires an explicitly configured durable Task Store and durable ActiveJob backend; production hosts still own real credential verification, business authorization, distributed rate limiting, TLS/ingress policy, cost/compute limits, observability, and side-effect idempotency.
