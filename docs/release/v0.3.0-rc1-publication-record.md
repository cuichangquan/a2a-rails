## Limits and next stable-release work

- SDK CI uses test-only loopback pinning and test CA; no fresh real public-DNS/public-CA endpoint probe was run for this artifact. Historical IAM-private controlled endpoint evidence is context, not a fresh artifact test.
- Optional independent audit [#113](https://github.com/cuichangquan/a2a-rails/issues/113) remains open and unperformed. TLS revocation, production IdP, host logging/APM, business authorization and operational budgets remain deployment responsibilities.
- Client IPv6-only destinations, streaming, gRPC and push notifications are unsupported. Default MemoryStore is process-local/non-durable.
- Potentially executed SendMessage/CancelTask timeouts have no automatic retry. Hosts own idempotency and reconciliation; durable queues/stores do not promise exactly-once effects.
- TCK is an informational scoped baseline with historical upstream mismatch/skips, not complete conformance certification.
- Stable `0.2.0` is retained; stable `0.3.0` needs RC adopter feedback, triage/retesting, final support/compatibility review and a separately approved fresh exact-artifact release.
- Gem publication does not approve public-production deployment, anonymous Cloud Run exposure or security certification. No Cloud Run/GCP/IAM/firewall changes or paid resources were made. [Deployment #11](https://github.com/cuichangquan/a2a-rails/issues/11) remains separate.
